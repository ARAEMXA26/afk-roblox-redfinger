## 📖 Cara Penggunaan Manual

Jika ingin mendownload script terlebih dahulu ke Termux:

1. **Berikan izin penyimpanan Termux:**
   ```bash
   termux-setup-storage
   ```
2. **Download script:**
   ```bash
   curl -O https://raw.githubusercontent.com/ARAEMXA26/afk-roblox-redfinger/main/roblox_booster.sh
   ```
3. **Beri izin eksekusi & jalankan:**
   ```bash
   chmod +x roblox_booster.sh
   ./roblox_booster.sh
   ```
